# 凍結時賠率保存及解釋因子修正（2026-11-18）

## 凍結時賠率
- 每5分鐘鎖定排程喺會期鎖點（首場 T−90）後，將 `odds_snapshots` 入面 `snapshot_at <= lockAt` 嘅最後一筆 WIN／PLA 賠率抄入 `lock_odds_snapshots`，另寫一行 `lock_odds_manifest`（鎖點、抄錄時間、場數、行數、最舊／最新賠率時間、過時場次、SHA-256）。
- 只增不改：同一會期只寫一次；之後再跑係 no-op。讀取時重新計 SHA，對唔上就 `verified:false`。
- 某場鎖點前最後一筆賠率早過鎖點20分鐘以上 → `partial`，`stale_races` 列明場次；完全冇賠率 → `missing`，唔補、唔用最終賠率頂替。
- 唔係引擎輸入，唔入凍結四揀指紋，唔影響凍結或對帳。
- 舊賽日唔倒填：`odds_archive` 只保留每組合最早一筆同最後6筆，冇鎖點時嘅價。研究比較舊賽日只可用「鎖點前最早保存」嘅早盤，並要標明。
- 讀取：`GET /api/analyze/lock-odds?date=YYYY-MM-DD[&venue=ST|HV]`（公開馬會賠率，返回每場 WIN／PLA 同鎖點時頭四熱門）。補抄：`POST /admin/api/lock-odds/capture`（管理員，規則同排程一樣，只限 `odds_snapshots` 仲保留嗰日）。

## 解釋因子（只改說明，唔改排名）
- 總分仍然只計檔位同負磅（R5 ablation）；LGB 特徵由 `dump-features.ts` 另計，今次冇改。
- 場地：由「完全同一字眼」改為同一跑道（草地／全天候）、今日場地前後一級。例：草地「好地至黏地」會計埋好地同黏地往績。
- 晨操：馬會每日都列踱步、游水，兩星期 20 幾課屬正常，舊規則 >8 課就扣分，幾乎全部馬都中。改為只睇快操同試閘：兩星期冇快操又冇試閘先標 −3，其餘中性。2026-09-01 至 11-14 2,427 匹次：0 課快操入頭四 25.6%，1–4 課 31–34%。
- 已凍結紀錄保留原文同原分數，唔重寫。
- 未處理：主模型 `going_starts／going_top3`、騎練 × 場地特徵同樣用完整字眼比對，屬模型輸入，要另過研究閘。
