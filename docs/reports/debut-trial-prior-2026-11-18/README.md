# 初出馬試閘先驗及公平盤口對照（研究閘報告，2026-11-18）

只作報告，冇升版、冇改凍結紀錄、冇寫入正式資料。

## 問題
2026-11-14 沙田18匹初出馬有6匹入頭四，引擎一匹都冇揀；今季種子評分初出馬97匹只揀過1匹。想知馬會試閘資料可唔可以幫初出馬建立更好嘅起步估計。

## 資料
- 官方賽果 `data/YYYY/results_*.csv`（烙號核對身份）；試閘 `trials/trial_results.csv`（2025-03-13 起，組內排序＝完成名次，落後秒數由完成時間計）。
- 引擎 `prediction_log`（v12 baseline）5月9日至11月14日 38 個賽日，唯讀匯出。
- 特徵（全部只用賽日前資料）：試閘次數、最近一次名次百分位／落後秒數、近三課最佳名次／平均落後、距最近試閘日數、未有試閘、最近一課不及格／勝出、場內匹數、檔位、班次、負磅、騎師賽前入頭四率、練馬師初出馬賽前入頭四率、練馬師整體入頭四率。
- 模型：L2 邏輯迴歸。驗證期（2026-05-01→07-31）用 2025-07-01→2026-04-30 訓練；測試期（2026-09-01→11-14）用 2025-07-01→2026-07-31 訓練。換馬門檻喺驗證期揀定，測試期只跑一次。

## 結果（測試期 196 場、20 個賽日、108 匹初出馬）
| 項目 | 引擎 | 試閘先驗 | 基準 |
|---|---|---|---|
| 初出馬排序 AUC | 0.653 | 0.644 | — |
| 對數損失 | 0.653 | 0.580 | 0.585（平均率） |
| 平均入頭四估計 | 11.3% | 19.0% | 實際 26.9%（29/108） |

- 排序：引擎喺初出馬之間本身已經揀得同試閘先驗一樣好；試閘資料冇額外分辨力。
- 低估：引擎俾初出馬嘅入頭四機會平均只有11%，實際27%，屬校準問題，但唔影響揀邊四匹。
- 換馬測試：最有機會嘅初出馬換走第4選，驗證期9次換馬換入中4匹、換走嘅都中4匹（±0）；測試期 1.959 → 1.964（+0.005，95% 區間 0 至 +0.016，只換2次）。單純放大初出馬機率（×1.31）測試期 1.959 → 1.954。
- 原因：第4選本身有約40%入頭四；最被看好嘅五分一初出馬只有43–48%，好極有限。初出馬整體27%係分散喺好多匹身上，難揀中邊匹。

**判斷：未通過研究閘。** 試閘先驗唔應該加入四揀。11月14日初出馬集中跑出屬波動多過系統漏洞。
若要再試，應將試閘特徵加入主模型重新訓練做完整回測（樣本更大、同其他特徵一齊學），唔好另開初出馬專用模型（Scarce starts never switch models）。

## 公平盤口對照（用鎖點前已有嘅賠率）
舊賽日冇鎖點時賠率；`odds_archive` 每組合只留最早一筆（多數係前一晚或賽日凌晨）同最後6筆。用最早一筆（全部早過賽日 02:00Z、即早過鎖點）做「早盤」：

| 196 場（20 賽日） | 平均中 | 四匹全中 |
|---|---|---|
| 引擎四揀 | 1.959 | 4 |
| 早盤頭四熱門 | 1.990 | 3 |
| 最終賠率頭四熱門 | 2.219 | 6 |

- 引擎減早盤：−0.031（95% 區間 −0.183 至 +0.123），20日入面12日追平或贏早盤。
- 之前「全季輸市場 0.26」係同最終賠率比，最終賠率包含鎖點後嘅資訊，唔公平。
- 早盤早過鎖點好多個鐘，所以真正鎖點時盤口應該介乎 1.99 至 2.22 之間。由今日起鎖定排程會保存鎖點時 WIN／PLA 賠率（`lock_odds_*`），之後先可以做準確比較。
